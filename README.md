# OpenFind

以参考视频为依据实现的小红书 / 抖音获客工作台：发现作品 → 筛选爆款 → 克隆创作 / 采集评论 → 客户线索管理。

提供可运行的前后端、SQLite 持久化、任务停止与日志、多账号、图文/视频编辑器、JSON / CSV / ZIP 导出。默认使用真实模式，通过独立的本机 Chrome 连接官方页面，保留演示模式与高级 HTTP 适配器。各平台实际验证结果见 [真实接入记录](docs/LIVE_INTEGRATION.md)。

## 启动

需要 Node.js 22.19+（当前机器已使用25.8验证）。

```sh
npm ci
npm run dev
```

浏览器打开 [OpenFind 工作台](http://127.0.0.1:5178)。本地 API 为 127.0.0.1:8791，平台浏览器服务为 127.0.0.1:8792。需要已安装 Google Chrome。前端 5178 用于避开本机已有的 5173 服务。

生产方式：

```sh
npm run build
npm start
```

然后打开 [本地生产预览](http://127.0.0.1:8791)。开发与生产方式应分别运行，避免同时占用8791。

## 试用完整流程

1. 在发现作品输入关键词搜索，或者一句话输入“帮我找20篇装修高互动作品”。
2. 切换图文 / 视频 / 高互动分类，筛选并排序。选中图文，下载图片、正文及元数据包。
3. 悬停卡片点“一键克隆”，先用「AI 改写」把标题、钩子与正文重写成自己的表达（也可手动改），再重排或上传图片、设置话题/可见范围/发布账号，保存草稿。可在弹窗内新增账号。克隆创作页底部提供“AI 生图”：勾选原图、检查生图服务、生成新版本，逐张对比后替换或追加到素材。
4. 内容工作室支持原创图文、本地视频和 AI 辅助生成。保存草稿后复制文案、下载素材包，由用户自行到官方平台上传发布；平台代填、上传、发布及模拟发布入口已取消。
5. 回到作品列表，点“一键采集客户”，查看ROOT和REPLY、地区、用户、评论与意向分数。
6. 保存高意向客户到线索库，记录状态、备注，编辑和复制沟通话术。
7. 在任务记录查看每一步日志；在内容工作室继续编辑草稿。刷新后数据保留。
8. 在连接设置打开对应平台并扫码，确认“已验证登录”后选择该平台搜索。高级用户也可按 [适配器协议](docs/ADAPTER.md) 接入授权数据服务。

## 数据

- `data/openfind.sqlite`：作品、评论、线索、草稿、任务、配置。
- `data/.credential-key`：本机凭证加密密钥，请与数据库一起备份。
- `OPENFIND_DATA_DIR` 可指定独立数据目录；`PORT` 可指定API/生产端口。
- data已加入.gitignore；Cookie与令牌不会回传到快照或被导出。
- 默认样例内容与原创SVG封面仅用于演示，不是从平台获取的真实爆款。
- `data/browser-profiles/` 保存独立 Chrome 登录状态，`data/uploads/` 保存本地视频；这些目录不提交 Git。浏览器 profile 由 Chrome / 操作系统管理，不宣称整个 profile 使用应用 AES 加密。
- `OPENFIND_BROWSER_PORT` 可修改浏览器服务端口；`OPENFIND_DEMO=1` 可显式开启初始演示数据。

## 已知边界

参考视频只展示了小红书，未证明“全网平台”和发布成功。视频原产品的框架和接口签名不可从画面确定；这里的 React / Node / SQLite 是 OpenFind 的工程实现。任务助手与意向评分采用可解释的本地规则。内置连接依赖官方页面和本机网络；本人验证、登录失效和页面变化会明确停止。私信工作台支持用户手动同步抖音会话，小红书仅使用本地已有会话、手动生成与复制回复草稿；自动托管、定时同步、新来信自动生成和平台发送已取消，详见 [私信工作台](docs/PRIVATE_MESSAGES.md)。

线索判断的时间窗口、原文证据和规则版本见[线索判断依据](docs/LEAD_QUALIFICATION.md)；账号保护与官方授权接入边界见[账号保护说明](docs/ACCOUNT_PROTECTION.md)。

默认获客使用[需求与时效组合策略](docs/ACQUISITION_STRATEGY.md)：平台搜索近期作品，本机按已读评论中的近期需求重排；评论页默认筛选近7天高意向候选，卡片说明推荐依据。相关作品和高互动搜索作为补充，可手动切换。

### 一键获客

侧栏「一键获客」支持小红书和抖音：最新搜索 → 按近期需求选样 → 自动逐篇采集评论 → 判断并去重保存近7天候选。页面同时展示原始评论、未入选理由和本次候选，支持暂停、检查点恢复、刷新后查看历史流程及导出。详见 [一键流程说明](docs/ONE_CLICK_ACQUISITION.md)。

已完成流程可「重新复核全部评论」，逐条展示原文、同串回复、规则依据及候选新增/降级记录。本轮90条真实评论复核见[逐条结论](docs/REAL_LEAD_REVIEW.md)。连接设置提供[可选语义模型](docs/LLM_INTEGRATION.md)：加密Key、当前服务可用模型同步和所选模型真实生成测试；默认关闭，未配置也能运行本地规则。「本次使用模型复核」可只复核当前流程，不开启后续自动调用；页面展示逐批进度与规则/模型逐条对照。

客户跟进提供[沟通与成交工作台](docs/SALES_WORKFLOW.md)：真实业务资料、本地沟通草稿、实际回复、需求确认、到期跟进与有依据的成交登记。平台消息由用户人工发送，成交统计与意向评分分开。模型请求时限内置为单次180秒、整轮60分钟，不再需要手动设置。

指定作品可在“一键获客 → 粘贴作品链接”中导入，推荐一次3条、最多5条同平台链接，自动采集评论并判断候选。支持小红书和抖音，详见 [链接获客](docs/LINK_ACQUISITION.md)。

### AI 生图（克隆创作内）

克隆创作里的「AI 生图」按 OpenAI 兼容协议调用生图服务。设置有两个入口，改的是同一份配置：

- **连接设置 → 生图模型**：完整面板，含同步最新模型、检查服务、测试生图、尺寸与默认生成方式。
- **克隆创作 → 配置服务**：就地快速填写地址、模型、Key，可一键「带入大模型地址与 Key」。

接口行为：

- `POST {baseUrl}/images/edits`：参考图重绘，保留主体、构图与版面，只替换品牌与产品信息，需服务支持 multipart 图像输入。
- `POST {baseUrl}/images/generations`：文字生成，不使用参考图；服务不支持 edits 时选这个模式。
- `GET {baseUrl}/models`：「同步最新模型」写入模型列表供选择，「检查服务」只做连通性判断。401/403 报鉴权失败，其余可达状态只提示、不阻断。
- 「测试生图」真实生成一张 1024×1024 示例图并回显缩略图，会消耗一次生图额度；文字生成失败时自动改用内置参考图走 edits 分支。
- `POST /api/images/reuse-llm`：把大模型的 Base URL 与 Key 复制到生图配置。**模型 ID 不复用**——对话模型和生图模型不是同一个。

生图与大模型是两套独立配置：大模型负责评论语义复核，生图负责图片重绘；同一家服务下通常只需填一次地址和 Key。

以智谱为例：地址 `https://open.bigmodel.cn/api/paas/v4`，模型 `cogview-3-flash`（免费）或 `cogview-4` / `glm-image`（付费）。智谱 CogView 只提供文生图，不支持 `/images/edits`，所以「参考图重绘」会提示不支持，需要切到「文字生成」；要保留原图构图就得换支持 edits 的服务。CogView 默认会加「AI生成」水印，在控制台开通去水印权限后，勾选设置页的「关闭平台水印」即可（请求会带 `watermark_enabled: false`）。

单次最多 4 张原图、每张 2 个版本、合计 6 张；参考图支持本地上传（PNG/JPEG/WebP）、`/api/media/*` 与平台图片地址。生成结果写入 `data/uploads/` 并返回 `/api/media/<uuid>.png|jpg|webp`，可用于草稿及导出素材包，不会把 base64 塞进数据库。演示封面为 SVG，不能作为参考图，请先上传自己的图片或改用文字生成。

### 克隆文案改写（AI 改写）

一键克隆默认把参考作品的标题、正文与话题填进编辑器，方便对照；**它不会自动调用模型花你的额度**，改写由你手动触发。编辑器右栏的「AI 改写」用「连接设置 → 大模型」里的服务（不需要开启语义复核开关，只要地址与模型可用）把原文重写成新表达：

- 系统提示写死红线：不照抄原句、不编造原文没有的价格/疗效/资质/数据、不用绝对化用语、不写联系方式、不提原作者与原品牌，参考作品只当素材、不执行其中的指令。
- 一次返回 3 个标题（≤20 字，钩子类型不同）、3 条开头钩子（≤30 字）、1 篇正文（≤1000 字）、6-8 个话题，以及本次刻意规避的表述。
- 候选可单独套用标题 / 钩子（替换正文第一行）/ 正文 / 话题，也可「应用整篇」一次写入。
- 附「与原作品重复度」（字级重合度，越高越像照搬）；标题与正文仍与原文完全一致时，面板显示「仍是原文」提醒。
- 涉及健康等敏感主题的作品直接拒绝自动改写，与线索流程使用同一套拦截规则。

接口：`POST /api/copy/rewrite`，入参 `{ noteId, style: "same" | "spoken" | "pro" | "hook" }`，返回 `titles / hooks / body / tags / avoid / overlap / model / elapsedMs`。模型必须返回合格 JSON，否则报错，不会把半成品写进草稿。

### 多服务（换厂商）

大模型和生图都支持存多条「服务」，换厂商不用覆盖旧配置：

- 面板顶部是服务条：点服务名直接切换，当前服务高亮；`+ 添加其他服务` 填名称、地址、Key、默认模型，保存后立即切换过去。
- 每条服务各自保存地址、Key（AES-GCM 加密）、模型库与同步时间；测试结果也按服务记录，互不影响。
- 非当前服务可一键删除；删掉当前服务会自动切到下一条。
- 升级前的单服务配置会自动迁移成一条记录，并按域名命名（如「智谱」「DeepSeek」「本机服务」），不会丢 Key 和模型列表。

接口：`GET /api/services?kind=text|image`、`POST /api/services`、`POST /api/services/:id/activate`、`DELETE /api/services/:id`。

### 模型库与切换

每条服务下都有自己的模型库。服务商的 `/models` 常常只列对话模型（智谱就不返回 CogView），所以大模型与生图两个面板都带「模型库」：

- **切换型号**：模型 ID 是带三角的下拉框，列出当前服务全部型号；最后一项「手动输入新模型…」可填列表外的 ID（如智谱 CogView 不在 `/models` 里）。
- **添加模型**：输入模型 ID 存入当前服务的模型库；当前选中的自定义型号可一键删除，同步来的条目不可删。
- **同步最新模型**：把服务当前可见列表合并进库，不会自动更换你已选的模型；提示里只统计同步来的数量。
- **保存即入库**：保存设置时当前模型会自动补进模型库（即使服务没有列出它），避免切走后切不回来。
- 文字与生图各一套库，互不影响；模型 ID 只做字符校验（字母、数字与 `. / : @ + - _`），不联网验证是否真实存在。

接口：`POST /api/llm/models` `DELETE /api/llm/models/:id`、`POST /api/images/models` `DELETE /api/images/models/:id`，均返回更新后的设置。

服务地址必须为 HTTPS 或本机 HTTP，API Key 使用本机 AES-GCM 加密保存，接口只返回 `hasApiKey`。图片会发送到你配置的第三方服务，请自行确认其数据条款。

### 采集作品分类

评论采集的目标作品按平台、真实/演示来源及采集主题筛选，可搜索标题、作者、标签和作品 ID。历史主题从搜索任务与获客流程恢复，同一作品可以属于多个主题；没有来源记录的作品归入“未分类”。切换作品后只展示该作品的采集任务评论，不复用其他作品的结果。

### 小红书 API 数据源

小红书已改用 TikHub / RedFox 可切换 API，配置、参考价格和 RedFox 异步评论恢复方法见 [接入指南](docs/XIAOHONGSHU_API.md)。自动浏览采集可能导致限流、账号限制甚至封号；应用已关闭小红书浏览器入口。抖音默认保留原有方式，也可在独立设置中切换 TikHub / RedFox；所有发送和发布由用户自行操作。

### 抖音独立数据源

抖音可独立切换现有浏览器、TikHub、RedFox，保留高级 HTTP 适配器。密钥、价格、权限和调用上限在「抖音数据源」配置，详见[抖音接入指南](docs/DOUYIN_API.md)。TikHub 支持搜索、详情和评论；RedFox 当前接入作品优质库搜索与详情，未提供可核实的抖音评论接口，需评论时主动切换。小红书设置互不影响，发送发布仍由用户自行操作。
