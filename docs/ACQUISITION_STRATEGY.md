# 获客默认策略

决策：用搜索寻找相关作品，用评论判断需求，按评论原始日期安排复核；点赞量用于内容参考，不决定客户价值。

## 日常工作顺序

1. 先用具体产品、使用场景和服务地区搜索，默认20条、最新发布。避免只搜宽泛行业词。
2. 当前结果按“获客优先”重排：已读样本有近7天明确需求 → 有近7天讨论 → 有评论但需求和日期未核实 → 无评论。
3. 优先给前3个相关作品做小样本评论采集，再决定是否继续。默认评论页展示近7天高意向候选，并按意向分、时间排列；可以查看全部时间和全部评论。
4. 近3天明确询价、购买路径或预约咨询先复核；4–7天次之；8–30天先确认需求是否仍存在。老作品下的新评论仍然优先。旧评论不能据此断定已经成交。
5. 主线不足时用“相关作品”补充；少量“高互动”探索用于发现持续有人咨询的老作品。两个入口是可选设置，点击后仍需提交搜索，不会自动增加请求或突破账户保护额度。
6. 对候选人工核对具体产品、地区、预算与服务能力。第三方评论中的询价不等于同意被营销，也不等于会购买自己的产品；不自动私信或回复。

推荐初始分配：约60%的人工研究精力看近期相关作品，30%查看已发现的活跃讨论，10%探索高互动作品。这是待业务反馈验证的起点，不是经训练的最优比例，产品没有在后台自动执行这一配额。

## 排序依据

“获客优先”是本机结果的采样优先级，与平台的综合/最新/最多点赞排序分开显示；只重排本次已取得的作品，不宣称覆盖平台全量内容。

有明确需求的样本按不同作者去重；作者自答、已解决需求、推广、日期缺失或异常不升级为近期需求。未读评论时只能用作品日期与总评论数初筛：近期作品优先，总评论数采用对数且封顶，避免评论总量压过需求证据。每张卡片显示判断理由。没有符合条件的评论时明确说明当前筛选无候选，提供查看全部评论按钮。

规则详见 [线索判断](LEAD_QUALIFICATION.md)。健康等敏感主题不使用评论建立个人营销画像；可用于公开内容选题，商业咨询应来自本人主动、明确授权的渠道。

## 用什么评估策略

按渠道记录：每100条已读评论中可复核的明确需求数、获准沟通后的有效咨询数、产品和地区匹配率、实际成交数、每个有效咨询花费的时间。不以采集总量、点赞量或软件分数当作成交成果。当前尚无足够实际成交数据，不能声称哪个渠道的转化率已被证明更高。

## 官方资料与适用范围

- [抖音视频搜索管理](https://open.douyin.com/platform/resource/docs/ability/search-management/video/)面向获批的自有品牌或产品关键词评价、咨询处理，并强调时效；不是无限制采集竞品客户的通用授权。该官方API只返回最近一天作品，不能将此限制误当成网页版搜索规则。
- [巨量引擎广告目标说明](https://school.oceanengine.com/product_help/content/668400000006/121544)区分点赞、评论等互动目标与有效咨询、留资等线索目标。以上组合策略是OpenFind的产品判断，不是平台推荐或保量承诺。
