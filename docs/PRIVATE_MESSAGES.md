# 私信草稿工作台

平台托管及发送已取消，适用于小红书和抖音。历史会话、回复草稿及发送记录保留在本机；启动服务时关闭旧会话的自动同步和自动建议设置。

## 使用步骤

1. 小红书已关闭浏览器会话读取，仅保留已有本地记录和草稿。抖音需要读取会话时，由用户点击“连接并同步官方会话”。选择联系人仅查看本地缓存；点击“刷新消息”才重新读取平台。
2. 根据已有聊天手动生成建议，或编辑文字并保存草稿。生成前明确确认将脱敏上下文交给配置的模型；没有真实来信或涉及敏感主题时不会生成营销建议。
3. 核对后点击“复制回复草稿”，自行到官方客户端粘贴并发送。复制只操作剪贴板，不表示已经送达。
4. 平台出现验证或限制时停止操作，按官方提示处理。手动触发的网页读取仍依赖平台页面，不能保证账号不受限制。

后台没有定时平台同步，也不自动处理新来信。网页每四秒刷新本机缓存，以显示手动生成的结果；这不会访问平台。

## 接口

- `GET /api/inbox`：读取本地会话与草稿。
- `POST /api/inbox/:platform/sync`：用户主动同步列表或指定会话。
- `PUT /api/inbox/threads/:id`：更新关联线索或停止联系；开启 watching/autoSuggest 返回 410。
- `POST /api/inbox/threads/:id/suggest`：手动生成草稿。
- `POST /api/inbox/threads/:id/drafts`：保存人工草稿。
- `POST /api/inbox/drafts/:id/send`：固定返回 410，不调用浏览器。
- `POST /api/inbox/drafts/:id/reconcile`：仅供历史未知发送记录人工触发只读核对，不会重发。

内容工作室的 publish/prepare/reconcile 接口及内置浏览器的发布接口同样返回 410。底层消息模块拒绝 send，已删除输入和提交消息的代码。底层发布模块仅保留拒绝操作的兼容入口。
