# 私信工作台

## 当前支持与验收范围

小红书普通账号通过本机官方网页版“消息”入口接入，不需要企业号 API。2026-10-18 的受控账号测试已完成：人工确认测试消息、官方会话刷新回查、收到测试回信、调用用户所配置模型生成待审建议、再次人工确认并发出模型回复。账号、聊天原文、模型凭证及验收截图保留在本机，不提交公共仓库。

抖音普通账号通过官方网页消息抽屉连接。2026-10-18 已用受控联系人验证：人工确认后单次发送，刷新官方会话回查服务器消息标识，真实收到测试回信、调用已配置模型生成建议、人工确认发送模型回复并再次取得回执。

两平台随后均通过后台自动同步复测：由测试联系人另发新消息，不手动刷新，后台自动读取并分别生成新的待审草稿，页面显示来信及依据，草稿保持未发送。同步会重新读取官方页面，避免断线后的旧 DOM 冒充最新消息。抖音企业号 `enterprise.im` 是另一条需官方权限的接入方式，不能套用于普通账号。

## 使用步骤

1. 在连接设置登录官方账号；看不到专用窗口时使用“显示扫码页”。已验证登录会直接提示，无需重复扫码。二维码页面截图不缓存；协议、验证码仍须本人在官方页面处理。
2. 打开“私信工作台”，连接并同步官方会话，选择具体联系人。只读取官方页面已经加载的消息，不宣称同步全部历史。附件提示回平台查看。
3. 可为每个会话开启每60秒检查同步。仅在本地服务运行期间工作；平台异常会暂停并显示原因，处理后手动刷新恢复。后台忙碌时跳过该轮，不挤占发送操作。
4. 可单独启用新来信生成建议，或点击手动生成。原评论只能关联同平台且原始用户标识一致的真实线索，不用昵称猜测。没有原评论时按实际聊天处理，不编造需求。
5. 建议使用现有模型设置，将脱敏后的最近20条文本、所关联原评论及业务资料发往用户配置的服务。默认不处理旧私聊；关注提示不当作客户意向。敏感主题转人工处理。模型错误单独显示，不冒充平台同步失败。
6. 编辑后保存新草稿，核对实际平台、发送账号、收件人及完整文字，再点击确认发送。新来信、原评论关联、业务资料或模型设置变化会使旧草稿失效。不会自动发送模型输出。
7. 发送仅提交一次，再刷新官方会话回查同一消息标识。无法确认时锁定为待核对，不自动重发。可“刷新官方会话核对结果”，该操作只读、不补发。没有匹配回执则保持锁定。

## 实现与边界

- 会话键由平台、登录账号、官方会话 ID 共同组成；不同账号同名联系人不会合并。
- 小红书 `data-message-id` 包含会话双方，不能用前缀判断发件人。方向依赖官方 `me/other` 消息气泡标记，标记缺失或冲突则停止读取。
- 抖音使用渲染节点上的官方会话与服务器消息标识，校验单聊双方及发送人。公开用户标识与会话 ID 分开保存，用前者关联同平台线索。不会调用 SDK 发送接口或读取认证票据。旋转列表转换为时间正序；未取得服务器 ID 的本人待发送气泡不能作为成功回执。
- 本机记录保存平台消息 ID 并去重；相对时间从“刚刚”变化为时分不会误判为新消息。显示平台原始时间，不伪造精确发送日期。
- 关联销售记录后，消息进入对应事件记录，注明原始平台时间及本机同步时间。不会根据模型判断自动登记报价、成交或付款。没有关联线索的聊天仍可单独查看与回复。
- 对方明确拒绝联系时阻止继续生成与发送。模型输入中的文字一律作为数据，不能指示程序执行发送、读取文件或更改配置。
- 普通网页版自动化依赖页面结构、登录和网络。没有绕过验证码、伪造设备、自动切换账号或规避限流，也不提供账号不受限制的保证。

模型网络层只在本机 DNS 返回代理虚拟地址 `198.18.0.0/15` 时，通过现有公共 DNS 解析同一服务域名；HTTPS 仍校验原域名证书。不会改变模型服务地址、向 DNS 发送 Key，或自动重试模型生成请求。

## 本机 API

- `GET /api/inbox`：本机缓存的会话与待审草稿，不触发平台读取或模型调用。
- `POST /api/inbox/:platform/sync`：会话列表；传 `threadId` 时读取该会话。
- `PUT /api/inbox/threads/:id`：按 revision 修改自动同步、建议、停止联系及关联线索。
- `POST /api/inbox/threads/:id/suggest`：明确确认将脱敏上下文送往已配置的模型服务后，生成待审建议。
- `POST /api/inbox/threads/:id/drafts`：保存人工草稿，不发送。
- `POST /api/inbox/drafts/:id/send`：确认完整文字和上下文摘要后单次提交。
- `POST /api/inbox/drafts/:id/reconcile`：刷新官方页面回查未知发送结果，绝不重发。

自动测试使用隔离临时数据库、本地模型协议服务及模拟 UI 响应；真实账号验收单独记录，不用测试样例替代平台结果。
