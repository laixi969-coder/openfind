# 可选语义复核

## 配置与连接

「连接设置 → 大模型」填写兼容服务Base URL（含`/v1`等实际前缀）、Key和模型ID。支持HTTPS与本机HTTP，无凭证URL及重定向转发。模型可以在同步列表中选择，也可以手动填写；不硬编码“最新”模型名称，不自动升级所选模型。

- `GET /api/llm`：返回配置、hasApiKey、模型列表、上次同步和测试时间，永不返回Key。
- `PUT /api/llm`：完整保存enabled、baseUrl、model、maxComments及可选apiKey；Key使用现有AES-256-GCM本机加密。更换供应商时必须重新明确输入或清空Key，不把旧Key传给新地址。
- `POST /api/llm/models/sync`：请求服务的`GET /models`，去重并展示当前账号可见列表及同步时间。列表可含非聊天模型，因此仍应测试所选模型。同步成功并不证明模型能生成文字。
- `POST /api/llm/test`：向所选模型实际调用`POST /chat/completions`，仅使用固定合成文本，核对JSON输出`{"ok":true}`；不拿真实客户数据测试。403/401/不支持JSON/无效输出都不能显示连接成功。

协议依据：[List models](https://developers.openai.com/api/reference/resources/models/methods/list)、[Create chat completion](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[JSON mode](https://developers.openai.com/api/docs/guides/structured-outputs)。兼容供应商仍需支持相应接口，OpenFind不声称所有第三方服务均可用。

## 执行与验证

默认关闭，无Key也可运行本地采集判断。启用后每5条评论一批串行复核，单次上限1–200条（默认100），默认每请求120秒超时，整轮最多900秒。请求时限可在设置调整为20–300秒，整轮为60–3600秒且不能小于单次请求。修改时限不影响Key、所选模型或有效语义缓存；旧客户端不传新字段时保留现值。延长的是本地等待，不能改变供应商或平台自身限制。也可在已完成流程点击「本次使用模型复核」，仅对该次调用模型，不改变自动复核开关。首次错误停止后续请求，逐批保存已完成结果；页面持续显示总范围、有效结果、本地排除和待处理数量。重试只处理尚无有效缓存的评论；服务重启会标记中断，不留永久运行状态。平台采集次数不受模型复核影响。刷新页面不会触发模型调用。

只发送评论文字、作品标题与同串回复角色/文字；不发送结构化昵称、ID、属地、Cookie或Key（Key仅用于模型服务Authorization）。号码、邮箱与URL遮蔽；敏感语境和作者自评在本地跳过，不发送到模型。文本中的其他个人信息不保证能自动识别，启用前应确认该服务适用的数据使用范围。

模型必须返回规定编号、结论、理由、原文引用和未知项。未知/重复编号、缺失结果、格式错误、没有证据的结论或与脱敏输入不匹配的引用均拒收；每条结果至少引用当前评论本人的原文，不能只引用父评论。若模型声称已购或结束但当前人及其同串发言没有明确证据，展示为待核实并注明证据校验拦截；不借用作者的购买经历。原始模型记录保留，不伪装为模型原本给出正确判断。不执行评论或模型里的指令。同串角色明确区分作者、当前评论的同一发言人和其他人，并补入当前发言人的后续回应；提示模型不能把别人的询问归给赞美回复，也不能把作者答复当作已购买或需求结束。语义缓存按输入、模型、配置及提示词版本校验；修改后失效。覆盖前的模型记录存入本机历史，便于对比修正。

模型只提供单独标注的补充建议；原文与规则结果始终可见，模型不自动把泛兴趣升成候选。待确认的模型建议可通过评论筛选查看，再由用户复核保存。「规则与模型对照」逐条展示两方结论、理由、模型引用和日期限制，可筛选仅规则入选、仅模型建议、类型分歧、本地排除与待处理。分歧不是准确率，也不意味着模型一定正确。

## 测试边界

测试套件使用独立临时数据库和本地真实HTTP兼容服务，验证模型列表同步、所选模型实际生成、加密凭证、401/重定向、原文引用、敏感排除、缓存、批次上限和故障回退。本地协议测试与商业服务实测分开记录。2026-10-17，用户保存供应商配置后，实际同步智谱服务的11个可见模型，所选 `glm-5.3-flash` 通过真实 JSON 生成连接测试。90条真实评论的完整复核统计与人工核对结论见 [真实候选复核](REAL_LEAD_REVIEW.md)。该结果仅证明本次所选模型与服务可用，不承诺所有兼容供应商或每次调用都成功。
