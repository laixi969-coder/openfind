# 账号保护与授权接入

核对日期：2026-10-17。账号保护不等于“防封保证”。本机浏览器成功登录、低频操作、真实发布成功都不能证明平台许可第三方自动化采集。

## 官方规则与可用路径

- [抖音用户服务协议](https://www.douyin.com/agreements/?id=6773906068725565448)：2.4、5.1、5.3 对未经授权的自动化接入、收集和商业使用有明确限制。低频不能消除这项风险。
- [抖音关键词视频管理](https://open.douyin.com/platform/resource/docs/ability/search-management/video/)：需申请特殊权限，关键词必须与自身业务紧密相关，不可申请通用品类词或竞品品牌词；文档说明仅返回最近1天的公开视频。搜索、评论列表及回复各有权限范围。不能将其宣传成任意行业全量搜索接口。
- [小红书官方客资工具](https://ad.xiaohongshu.com/next_help/home)：可使用平台客资收集及主动咨询链路；具体接口、准入和费用以后台与官方审批为准。
- [小红书专业号合规经营指南](https://ad.xiaohongshu.com/next_help/docs/cfa457375a0dffd3bd04453f42b9731e)：关注资质、主体一致、导流信息和批量同质化运营限制。
- [小红书专业号资质规则](https://ad.xiaohongshu.com/next_help/docs/195c5fe505c71b4b0335a2fe0d61d8e0)：医疗等行业有资质要求，不能把普通个人号登录视为行业营销许可。

HPV等主题可作公开内容研究。个人获客应通过用户主动提交并授权的咨询或官方留资流程，不从评论推断个人感染、治疗或其他敏感状态后进行营销。

## 已实现的本地约束

1. 全局单个采集任务；真实任务每次1–100条，不允许不限量。
2. 真实读取批次之间至少15秒，跨任务也生效。页面自主加载的网络请求不等于批次计数，因此不宣称每15秒仅一个HTTP请求。
3. 每个平台每日搜索最多10批、评论40批、发布5次、素材预览上传10次（预览上传至少间隔60秒）。计数从保护功能启用后开始，按UTC日期归档。这是本地保守默认值，**不是平台公布或认可的安全额度**。
4. 验证、403/429、频繁操作提示立即暂停；连续3次普通失败也暂停。不自动重试、换号或扩大采集。
5. 暂停状态持久化，进程重启或日期变化不自动解除；用户处理官方提示后在连接设置恢复。恢复前检查当前登录和验证页面，恢复不清零日额度。
6. 同条件5分钟内的足量搜索/评论结果可复用；缓存沿用首次实际采集时间，命中缓存不会延长新鲜度。搜索可手动勾选刷新。
7. 平台要求本人验证时保留页面，验证完成后可重试同条件任务继续读取；源码中的常规抖音搜索入口为 `/search/关键词`，不再从精选信息流进入。
8. 发布核对账号、正文、标题和可见范围；结果不确定时禁止重复提交，先核对官方作品管理。仅取得真实ID和链接才标为发布。
9. 本机凭证加密保存，平台使用独立Chrome登录目录；普通浏览器登录不会自动复制给OpenFind。没有承诺整个Chrome目录由应用AES加密。

本地缓存、证据和人工复核可减少重复访问与误触达，但长期商业运营仍应使用平台批准的账号、权限、关键词与官方留资渠道。当前HTTP适配器是连接协议，填入一个HTTP地址本身并不能证明其获得官方授权。
