# 工程审查修复 · 2026-10-23

本轮处理本机获客工作台审查中的10项问题，不引入产品用户登录、多租户或订阅计费。已有的 README 本地修改和 ROADMAP 未纳入此次提交。

| 审查项                  | 修复                                                                                                                                                                                 |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| F1 适配器凭证跨地址转发 | 换地址时须重新输入或明确清空现有令牌/Cookie；凭证记录目标地址，其他账号保存的 Cookie 也不会因全局换地址而转发。旧配置在地址变更前绑定原目标。                                        |
| F2 公网明文传输         | 保存和实际发送两处校验，仅允许 HTTPS 或本机 HTTP，拒绝 URL 内嵌凭证、查询参数与片段；历史公网 HTTP 配置同样不能发请求。                                                              |
| F3 回填覆盖草稿         | 外部请求返回后在 SQLite 事务内重新读版本，只更新未发生变化的草稿；编辑/删除均返回409，保留新编辑且不复活删除记录。                                                                   |
| F4 上游响应无限读取     | 采集与适配器在流读取过程中执行8MiB限制，超限取消流，保留不确定计费防重标记。模型分别限制文字2MiB、图片60MiB。                                                                        |
| F5 状态轮询容量         | 按作品预分组评论、批量预加载模型复核与业务关联，缓存快照、gzip传输、ETag/304；SQLite本进程/跨进程变更与分钟级时效令缓存失效。浏览器只允许一个在途状态请求。                          |
| F6 模型费用与重试       | 日调用数、文字token、预估金额上限；单次输出token限制；全局及分服务持久化预留账本，超限不发送。付费请求持久化防重/响应回放，浏览器刷新与网络重试保留同一编号，达到80%预算时显示提示。 |
| F7 模型出网脱敏         | 在文字请求的最终出口统一脱敏，包括正文、私信、评论和方法卡；JSON资料逐字符串处理，保持数字和结构有效；生图文字提示也脱敏，图片仍按操作发送给指定服务。                               |
| F8 清除与保留规则       | 设置页提供保留天数、无引用素材/过期生成与模型回执的预览清理，以及客户资料级联清除预览。防重摘要保留；清除依赖任务时同步处理检查点，备份完整性仍可校验。                              |
| F9 自动备份与可见性     | 正常模式下应用运行期间每日自动执行备份，独立子进程校验快照、密钥和素材，保留7份；有跨进程租约、最近成功/失败/过期状态、手动备份和可配置外部目录。                                    |
| F10 服务缓存隔离        | 缓存纳入服务ID/地址/模型/凭证摘要；整轮复核固定服务快照。更换同名模型的供应商不会命中旧缓存，也不会将后续批次静默发给新供应商。                                                      |

## 使用

连接设置 → **数据安全与预算**：

- 模型默认每日最多100次文字调用、20次生图调用、200000个预留文字token，每次最多输出4096 token。默认预估金额上限50元，输入100元/百万token、输出500元/百万token、图片10元/张，均为保护估算参数，**不是任何服务商的实时价格**。请按实际使用服务中最贵的费率调整。金额按整数分计算，超时不返还预留；本地估算无法代替供应商真实硬额度。
- 同一浏览器遇到不确定结果时重试会沿用请求编号；确定要再次生成时，可在供应商核对后点击“允许新建请求”。已完成且保留的原始响应可直接回放；被清理的旧响应只保留防重标记，不会自动重新计费。显式调用API时可提供 UUID `Idempotency-Key`；同一编号不能用于不同操作或内容。
- 自动备份默认启用，首次启动等待30秒，随后每分钟检查是否满24小时；测试/演示模式不调度。应用关闭时不执行。默认位置为数据目录同级的 `<数据目录名>-backups/`，同盘副本不能防整盘损坏，可改为外部磁盘。失败会保留错误并重试，不删除最后成功副本；超过26小时或从未成功会提示。
- 清理默认保留30天，须先预览再确认；文件仍被草稿等有效记录引用时保留。过期生成记录、原始模型回执可以清理，防重标记保留。不会自动删除客户记录。
- 清除客户按平台、来源和用户标识选择关联评论/线索/沟通/模型记录，以及依赖的任务/检查点。预览后数据发生变化需要重新预览。可明确选择同时删除**当前配置备份目录**中的全部受管快照；其他目录、Time Machine、导出文件、第三方平台和手写复制内容仍需另行处理。重新采集也可能再次导入该用户。
- 资料维护时拒绝新的写操作；采集、会话或生图操作未结束时拒绝开始清除。不会为了清理而抹掉请求防重标记，或伪造已完成的分页检查点。
