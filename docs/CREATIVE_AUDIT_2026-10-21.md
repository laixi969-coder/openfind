# AI 创作与素材流程检查（2026-10-21）

本轮按业务不变量检查：请求必须使用用户确认的服务；结果不明时不得静默重复收费；已完成素材必须可找回；保存只确认请求发出时的内容；导出包必须包含实际素材。

## 修复

- AI 改写与生图提交携带服务 ID、模型快照。编辑器打开后切换服务，旧窗口提交会明确拒绝；旧生图配置窗口也不能覆盖新选中的服务。请求内部固定使用开始时捕获的服务凭证。
- 生图连通性测试严格使用所选模式，失败后不再切换接口重复生成。
- 生图请求使用请求编号和内容摘要去重；运行中、失败后和完成后的相同编号均不会重新调用供应商。用户可明确新建请求，界面提醒可能再次计费。
- 批量生成前先验证全部参考图。每张完成的图片立即落盘并记录，后续失败返回已有图片和错误提示。重启时未完成请求标记为失败，不自动重提；最近 30 条记录可查询，编辑器按原图恢复相关结果。
- 草稿使用版本号拒绝旧版本覆盖，已删除草稿不再被旧窗口复活。保存响应迟到时仍保留后续编辑的未保存状态；存在未保存修改时隐藏旧版本下载入口。保留用户主动清空的正文。
- 保存时检查本地素材是否存在且为文件。生成图使用时限制数量，取消静默截断素材。
- 远程图片导出下载并打包实际图片字节，不再用 URL 文本冒充图片。下载失败明确中止；本地素材保留正确扩展名，视频继续包含在导出包中。

## 验证

- 构建：`npm run build`。
- 单元/API：`npm test`，包含服务切换、失败不重试、批次部分成功、请求重放、无效参考图预检、草稿版本冲突与删除后保存回归。
- 浏览器：`npm run test:e2e`，新增延迟保存响应期间继续编辑的回归，确认最新输入仍未保存，第二次保存后数据库含最新内容。

## 边界

本地请求去重不能消除供应商已接收请求但未返回结果时的计费不确定性，因此失败请求不会自动重提。明确新建请求可能再次计费。草稿中的远程图片仍保留原链接，并非保存时全部备份；链接过期会导致导出明确失败。测试使用本地模拟供应商，没有调用真实付费模型。
