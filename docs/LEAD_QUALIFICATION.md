# 线索判断的依据与边界

OpenFind 当前使用本地规则引擎 `intent-rules-2.2`，不是调用远程模型，也没有把普通关键词匹配包装为智能 Agent。每条判断保存规则版本、评估时间、评论原始日期、匹配原文、加分项和排除原因。分数用于人工排序，不代表购买概率。

## 时间如何影响判断

判断使用评论发表日期，而非作品日期、采集日期或导入日期。老作品可能有新需求，新作品也可能只有作者自荐。缺失、无效或明显未来日期按未知处理，不补写当前日期。

| 评论距今  | 时效分 | 使用方式                         |
| --------- | ------ | -------------------------------- |
| 0–3 天    | 30     | 优先查看明确需求                 |
| 4–7 天    | 24     | 近期咨询                         |
| 8–30 天   | 12     | 结合实际购买周期复核             |
| 31–90 天  | 3      | 总分上限45，不推荐自动筛入高意向 |
| 超过90天  | 0      | 总分上限45，保留作内容研究       |
| 未知/异常 | 0      | 总分上限40，待核实               |

这些是产品初始规则，不是经训练得到的转化预测。时间久只能降低优先级，不能据此认定对方已经购买。家具装修与日用品的购买周期不同，后续应根据用户授权取得的真实转化结果调整规则，并记录版本。

## 需求与排除项

| 依据                         | 分值/处理              | 例子                                        |
| ---------------------------- | ---------------------- | ------------------------------------------- |
| 明确需求或询价               | +35                    | 想买、求报价、多少钱、求推荐、10w吗         |
| 询问购买/预约路径            | +20                    | 求链接、有链接吗、在哪买的、怎么预约        |
| 同时表达近期计划             | +10                    | 本周想买、急需                              |
| 只有赞美或讨论               | 总分最多15             | 好看、谢谢分享                              |
| 明确已购买、已解决、不再需要 | 0，不推荐              | 已经买了、不用了                            |
| 疑似商家推广                 | 0，不推荐              | 厂家直销、私我报价                          |
| 健康等敏感主题               | 禁止加入个人营销线索库 | HPV相关作品下的中性询价也不建立健康营销画像 |

总分上限99，高意向阈值50，并且不能存在排除项。规则对否定表达、反讽、上下文仍可能误判；高分必须人工复核原评论与所属作品。不能从高分推断购买力、病情或真实身份。

例如：昨天的“想买，多少钱，求链接”得85分；120天前的同句得45分，不推荐；“已经买了，谢谢推荐”得0分。仅近期发表“真好看”最多15分。

作者自己的回复、无文字评论也不作为购买客户。规则2.1增加常见口语问法与否定表达，真实样本复核发现的表达补入回归测试。

## 产品落实

- 评论页按原始时间排序，提供全部、近3/7/30/90天筛选；高意向筛选使用完整判断。
- 评论详情和客户跟进展示原文证据、日期和规则版本。
- API 在保存线索时再次核对所属作品，敏感主题不能靠绕过前端筛选入库。
- 线索展示和导出会重新计算时效，避免旧分数长期保持“高意向”。原始证据和跟进备注不改写。
- “已购买”排除项默认归档；其他低分信息可由人工保留，不能自动视为已确认客户。
- 话术留在本机供人工编辑、复制，程序不自动私信或评论获客。

## Skill 或 Agent 的位置

当前确定性规则便于审计和测试，不依赖模型密钥。后续可增加语义复核模块处理否定、上下文、具体产品相关性，但模型也必须返回引用证据、无法确定时标为待确认，并服从日期和敏感主题的硬性限制。没有配置模型、授权数据与评估样本前，不宣称已有真实智能获客 Agent。

规则2.2依据本轮真实评论补充「链接给一个」「礼貌问价」「什么价」等表达，并回归否定请求。流程候选默认限制近7天，仍需人工核实匹配度。
