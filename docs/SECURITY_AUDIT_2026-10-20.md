# OpenFind 漏洞与缺陷检核（2026-10-20）

本轮从四条不变量检查当前工作区：密钥只能发送给其所属服务；外部素材不能访问本机或内网；异步结果只能更新发起请求的配置；导出包必须包含用户实际创作的素材。保留开始时已有的未提交修改，不读取真实凭证，不调用真实付费模型，不改变平台账号状态。

## 已修复

| 问题                              | 触发条件与影响                                                                             | 修复                                                                                                                  |
| --------------------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 复用服务残留旧密钥                | 生图配置有 Key，而被复用的文字服务无 Key：旧生图 Key 会随新地址发送                        | 显式复制空 Key，并清除旧同步列表和测试状态                                                                            |
| 批量请求串用密钥及异步结果串写    | 生图批次等待期间切换服务：后续请求读取新 Key 却继续使用旧地址；同步/测试完成时写入当前服务 | 生图批次捕获固定 Key；文字和生图同步/测试按原服务 ID、地址、模型及 Key 校验后回写；删除或修改配置后丢弃过期结果       |
| 不可信图片 URL 可访问内网（SSRF） | 参考图或模型返回的结果 URL 指向本机、内网、元数据地址，或公网地址重定向到内网              | 独立素材下载通道；每跳校验协议、凭证与 IP；连接时仅解析并使用公网 IPv4，避免 DNS 校验与连接之间换地址                 |
| 下载大小限制生效过晚              | 服务端持续返回无 Content-Length 或超大响应：完整读入内存后才报错                           | 参考图 10 MiB、结果图 20 MiB，逐块计数并取消超限流；限制模型 JSON 和内嵌 base64 大小；参考图校验 PNG/JPEG/WebP 文件头 |
| 上游错误回显敏感内容              | 生图服务将 Key 或提示词放入错误正文，接口直接回传                                          | 对外仅返回 HTTP 状态与本地解释，不回显上游错误正文                                                                    |
| 视频导出缺少实际视频              | 保存本地视频草稿后下载素材 ZIP，仅含 JSON 和正文                                           | 按受限本地素材路径读取视频，并打包为 video.mp4 / video.webm / video.mov                                               |

实现：`server/remote-media.ts`、`server/images.ts`、`server/services.ts`、`server/llm.ts`、`server/index.ts`。

## 验证

- 原始基线：119 项测试通过。最终当前工作区：128 项测试全部通过（含工作期间其他修改新增的测试）。
- 新增安全测试：内网及特殊 IP 编码拦截、重定向逐跳校验、流式超限取消、无 Key 复用、异步结果归属、批量请求中途切换服务、错误正文脱敏。
- API 回归：实际视频字节进入 ZIP；真实 PNG 可生成素材，伪造 PNG 被拒绝。
- 浏览器：20 项端到端测试通过，覆盖搜索、采集、草稿、客户跟进、配置与刷新持久化。
- `npm run build` 通过；Vite 提示已有主包超过 500 kB 的体积警告，不影响构建。
- `npm audit --json`：0 项已知依赖漏洞。
- 修改文件的 Prettier 检查与 `git diff --check` 通过。

测试使用临时 SQLite 与本地模拟模型服务器。公网重定向用受控响应测试，不访问真实内部服务。媒体 DNS 使用现有公网解析器；不可信素材目前只支持公网 IPv4，IPv6 地址和仅内网可达的素材不支持。用户主动配置的本机模型服务仍可使用。

本轮是有范围的代码检核和回归验证，不等于证明整个系统不存在其他漏洞。未进行真实平台账号操作、真实模型计费调用或完整渗透测试。工作区其他正在进行的修改不纳入本报告成果。
