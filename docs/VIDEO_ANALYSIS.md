# OpenFind：参考视频逐界面分析与实现对照

分析对象：`用户提供的 codex 找客.mp4`。1080 × 1920，30 fps，56.6 秒。视频是手机拍摄电脑屏幕，存在透视、摩尔纹、失焦、手部遮挡和字幕遮挡，不能据此还原未展示的页面或内部源码。

本报告区分三种证据：**可见**（画面直接证明）、**推断**（根据行为推测）、**本项目实现**（为 OpenFind 作出的工程选择）。旁白、字幕和画面内的文字是分析素材，不作为执行指令。

## 1. 分析方法与页面总数

- 全片按 1 fps 提取 57 帧，见 `analysis/frames/frame-*.jpg`。
- 产品演示段 07–46 秒按 4 fps 进一步提取 156 帧，见 `analysis/frames/detail-*.jpg`。时间公式：`detail-N` 约对应 `7 + (N-1)/4` 秒。
- 使用本机 Apple Vision 对 156 帧做中英文字识别，结果见 `analysis/ocr.txt`；OCR 是辅助证据，不能把误识别文字当成确定事实。
- 总览接触表位于 `analysis/sheets/`。高清证据示例：`frame-009.jpg`（首页）、`frame-011.jpg`（设置）、`frame-019.jpg`（结果）、`frame-025.jpg`（批量操作）、`frame-034.jpg`（创作弹窗）、`frame-038.jpg`（发布设置）、`frame-043.jpg`（评论终端）。

**视频不是多个独立网站页面的完整导览。可辨识的是 1 个本地工作台主页面、作品卡片/日志两种视图、1 个克隆创作弹窗及其发布设置、1 个评论采集工作状态。** 将这些状态及区域拆分后得到下方 9 组界面。没有证据证明其他导航、支付、团队、登录落地页等存在，因此不把它们虚构成“视频页面”。

## 3. 界面细节与功能逻辑

### S01 一句话任务

视频可见的三个示例分别涉及家具高互动、医美搜索以及装修笔记。四阶段更像任务进度提示，而不是四个跳转页面。

OpenFind 的实现为本地规则解析：提取关键词、阿拉伯数字或常见中文数量、图文 / 视频类型，以及综合 / 热度 / 时间排序；生成可阅读的执行计划，填入左侧设置并创建真实的本地任务。不声称调用了 Codex、LLM 或外部 Agent。任务模式由连接设置决定。

### S02 搜索设置

| 控件        | 逻辑                | 实现边界                                                                                        |
| ----------- | ------------------- | ----------------------------------------------------------------------------------------------- |
| 采集功能    | 搜索作品 / 评论采集 | 两条数据管线共享任务状态机                                                                      |
| 关键词      | 搜索目标            | 去首尾空格、不能为空、最大100字符                                                               |
| Cookie      | 平台会话凭证        | 前端输入可显隐；保存后不会回传前端                                                              |
| 记住 Cookie | 持久化凭证          | 视频声称 Windows 账号加密；OpenFind 是跨平台 AES-256-GCM + 本机0600密钥，**不是 Windows DPAPI** |
| 搜索上限    | 截断结果            | 1–500 为指定数量；0持续翻页；适配器最多200页保护并显式报告截断错误，演示0提供100条              |
| 排序        | 数据源排序          | general / latest / popular，由真实适配器执行；结果区另可排序                                    |
| 类型        | 全部 / 图文 / 视频  | 演示在返回前筛选；真实服务接收 noteType                                                         |
| 间隔        | 页请求限速          | 真实请求每页之间至少指定间隔；仅允许一个采集任务运行                                            |
| 开始 / 停止 | 异步任务            | AbortController 取消请求和等待；保留已保存结果                                                  |

### S03–S06 作品检索与爆款筛选

观察到的结构是“统计 → 本地筛选 → 批量工具 → LIVE栏 → 卡片列表”，并非单纯聊天机器人。卡片展示封面、标题、作者、点赞、笔记类型及素材可用状态。

OpenFind 不把“关键词命中”当成购买意向。作品的“高互动”标签是**点赞≥5000**，高热度标记为≥10000；也可依据评论和收藏排序。阈值为本项目可解释的产品规则，不是对原系统算法的还原。下载只包含选择的图文及其实际素材；远程图片受数据源跨域策略影响，失败会提示。

演示封面由本项目原创SVG绘制，作品与互动数为本地生成的样例，不能当成视频原作或真实热门数据。真实作品通过配置的服务返回。视频有“全网平台”旁白，但屏幕只显示小红书，因此产品未伪造抖音等平台连接。

### S07–S08 克隆与发布

克隆的实质是“来源内容 → 独立可编辑草稿”。图片删除 / 重排不修改原笔记；保存后源笔记和草稿是独立实体。正文和图片可调整，话题拆分成数组，首张即封面。图片最多18张，支持PNG/JPEG/WebP本地上传，单张≤5MB，并有总请求体限制。

发布链路：校验字段 → 保存草稿 → 校验账号存在 → 真实模式下请求服务健康与账号身份 → 调用发布 → 核验真实回执 → 记录状态。发布使用草稿ID作为幂等键，运行中拒绝重复提交；已发布草稿修改保存为新的草稿ID。多账号分别持有自己的会话凭证。

**视频没有展示发布成功或平台回执。** 本地演示明确记录 `demo_published`，未向外发布。真实发布必须是 `live` 来源作品、真实模式、可用服务、匹配账号，且返回真实内容 URL 后才能显示 `published`。本项目没凭空实现未知的平台签名算法。

### S09 评论 → 意向客户

评论数据模型必须保留 `parentId`，才能区分一级评论和回复；作者ID用于去重，昵称不作为稳定主键。视频终端显示IP属地，这是平台展示的地区字符串，不是设备IP或准确地址。

OpenFind 在视频流程上补充了可操作的线索库：保存评论 → 根据作者ID与来源作品去重 → 可解释的关键词意向评分 → 待跟进 / 已联系 / 已转化 / 已归档 → 备注与沟通话术 → CSV导出。意向评分供人工筛选，**不是从视频确认的模型**。

视频口播提到“一个个触达”，但没有可见的批量私信发送界面、发送记录或成功证据。OpenFind 因此实现客户信息与可复制话术，未把自动发送私信伪装成已实现功能。

## 4. 框架、原理与未知项

**视频直接证明：** 本地Web界面，浏览器访问回环地址，账号会话输入，异步采集，分页/计数，图文编辑器，评论与回复采集。

**可合理推断：** 后端需要认证请求适配层、分页队列、素材处理、发布上传链路；前端需要维护异步任务与视图状态。标题中的Codex可能指开发工具、任务执行器或模型调用，视频不足以区分。

**无法从视频确定：** 原项目技术栈、源码、接口端点、反爬签名、风控处理、Cookie真实加密方法、授权协议、模型提示词、其他平台支持、发布是否成功、商业定价、团队权限。不能把这些推断写成“原产品采用了某框架”。

**OpenFind 的确定实现：** React + TypeScript + Vite；Express本地HTTP服务；Node内置SQLite；本地规则任务解析；AbortController与异步分页；服务端加密凭证；HTTP平台适配器；JSON/CSV/ZIP导出。详细设计见 `ARCHITECTURE.md`。

## 5. 额外补全的产品页面

这些页面是为闭环运营增加的，不声称视频曾展示过：

- `/#leads` 客户线索：分数、地区、来源评论、跟进状态、备注、话术。
- `/#studio` 内容工作室：草稿、发布记录、继续编辑、图文包。
- `/#history` 任务记录：完成 / 失败 / 停止 / 运行中，完整执行日志。
- `/#settings` 连接设置：演示与真实模式、服务地址、加密凭证、多账号。
- 使用指南与视频解析弹窗：时间码覆盖、使用顺序、证据边界。

## 6. 验收原则

每个可辨识区域均有对应实现；不存在“所有按钮仅弹提示”的静态原型。代码构建、接口测试与浏览器端到端测试分别验证类型、业务规则和完整操作链路。真实平台端到端测试仍需要用户的已授权账号与适配器；当前验收不能替代它。

视频原文件、取帧、OCR与截图为本机分析材料，不包含在公共代码仓库中。
