# 抖音数据源

设置 → 抖音数据源：选择现有浏览器、TikHub、RedFox，或原有高级 HTTP 适配器。首次使用保留原来的连接方式；选择后保存生效。与小红书的数据源、API Key 和请求上限分别保存，互不改变。

## 能力与权限

- 浏览器：保留原有搜索、链接解析、详情与评论采集，需要本人登录及平台读取权限，仍受本地额度、间隔和平台风控约束。
- TikHub：专用 Search V1 搜索接口、App V3 分享链接详情、App V3 评论分页。保留评论接口随附回复，不额外展开全部二级评论。需有效 API Key、余额及对应接口权限；不传抖音 Cookie。
- RedFox：本次接入优质库作品搜索与详情（T+1），当前公开抖音目录没有可核实的评论接口。因此评论采集、一键获客和链接获客会在外部请求前明确阻止。可先在发现作品中搜索；需要评论时主动切换 TikHub 或浏览器，再选择已保存的作品采集。不会把“评论数量”误当作评论正文，也不自动回退供应商。
- 高级 HTTP：保留已有适配器协议和账号配置，仅显式选中时使用；供应商密钥不会发送给该适配器。

Key 按平台和供应商分别加密，不在设置响应中返回；若供应商允许同一 Key 使用多个平台，可分别填写。不自动复制已有小红书密钥。保存本身不收费，可选“保存并测试抖音搜索一次（可能收费）”调用一页搜索，不入库。

## 参考价格（核对：2026-10-20）

| 方式 | 参考价格 | 说明 |
|---|---|---|
| 浏览器 | 本应用不收供应商 API 费 | 平台权限与网络等成本另计 |
| [TikHub](https://tikhub.io/douyin-api) | 搜索 US$0.01/请求；多数其他抖音接口 US$0.001/请求起 | 搜索无量折扣；具体详情、评论端点价格、失败计费以控制台为准 |
| [RedFox 搜索](https://redfox.hk/apis/douyin/774OBKK0) / [详情](https://redfox.hk/apis/douyin/0OT1E306) | 最低¥0.02/次起 | 累计调用阶梯价格，优质库并非全量实时结果 |

按请求而非作品条数计费。搜索每页数量可能少于目标，会按游标继续读取到目标条数、末页或请求上限。RedFox 类型筛选在本地执行，可能消耗额外分页；其热门排序是供应商热度（阅读数）而非精确最多点赞。

默认每步骤最多20次 API 请求，范围1–100；整个获客流程含多个步骤，因此不是整个流程的费用上限。不自动重试付费请求，不自动切换数据源。缓存按平台、供应商和身份隔离，切换后不会拿另一数据源的结果冒充新采集。

第三方服务权限不等于抖音官方授权。私密、删除或地区限制内容可能不可访问。发送、代填、发布保持关闭，草稿复制和素材导出后由用户自行操作。

## 验证

使用隔离数据库和模拟响应验证路由、分页、密钥隔离、预算、RedFox 评论前置阻止及浏览器兼容性。真实接口需要有效密钥；没有密钥时不声称已经完成供应商实测。

接口文档：[TikHub Search V1](https://docs.tikhub.io/370212773e0)、[分享链接详情](https://docs.tikhub.io/186826220e0)、[评论](https://docs.tikhub.io/186826225e0)。
